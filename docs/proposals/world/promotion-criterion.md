# World promotion criterion proposal

**ID:** `proposal.world.promotion-criterion`
**Status:** `proposal`
**Depends on:** `proposal.world.atlas-scope`
**Proposes changes to:** `design.content.regional-promotion`

This proposal is nonbinding. It makes no catalog entry or scenario ready.

An atlas subject would enter a scenario composition only when at least one independently varying state, constraint, or attributable choice inside it can change a modeled actor's feasible actions, accessible observations, or settlement outcomes in that scenario. Economic importance, historical familiarity, available research, map presence, or narrative interest alone would not qualify.

Promotion would identify the internal owner whose independent state matters, the Fed-facing channel affected, the stable interface, and the aggregate share replaced. A region itself would remain non-owning. If only an aggregate output matters, the scenario would retain a typed adapter or residual rather than create shallow institutions and firms.

The decision would occur before initialization from reviewed catalog entries and researched opening state. Runtime salience could foreground an existing subject but could not promote it causally. Demotion or fallback would reconcile all owned quantities and pending commitments into the declared residual.

Acceptance would refine the evidence standard in `doc:design.content.regional-promotion`; it would not approve any candidate, fidelity tier, provider, period profile, or manifest selection.
