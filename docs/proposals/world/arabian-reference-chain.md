# Arabian reference chain proposal

**ID:** `proposal.world.arabian-reference-chain`
**Status:** `proposal`
**Depends on:** `proposal.world.promotion-criterion`
**Proposes changes to:** `design.content.regional-promotion`, `design.content.instrument-and-product-families`, `design.economy.opening-conditions-and-transmission`

This proposal is nonbinding. It makes no catalog entry or scenario ready.

The Arabian Peninsula would become the first cross-era worked resource composition. Reusable primitives would receive period-specific boundaries, country allocations, rights, capacity, inventory, law, pricing institutions, currencies, accounts, and opening state. An early-2006 profile would be one future reference and calibration composition, not the atlas default.

The primary lanes would remain independently owned: crude extraction and refined petroleum; natural gas, liquefaction, transport, regasification, and downstream gas or power use; source water, treatment, desalination, distribution, and consumer eligibility; and export receipts, currency, reserve, banking, freight, and sovereign-asset channels. Physical delivery and benchmark observations could feed a separately selected futures composition only when margin, basis, delivery, or default affects a modeled decision.

`region.me.arabian_peninsula` would remain scope only. It would reference versioned sovereign, watershed, coastal, production, infrastructure, and shipping overlaps without owning reserves, output, inventory, revenue, prices, or policy. Country institutions and firms would be selected explicitly when their independent action matters.
