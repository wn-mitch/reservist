# Arabian promotion sequence proposal

**ID:** `proposal.world.promotion-sequence`
**Status:** `proposal`
**Depends on:** `proposal.world.resource-truth-and-estimates`, `proposal.world.ownership-and-interfaces`, `proposal.world.title-custody-and-transformation`
**Proposes changes to:** `design.content.regional-promotion`, `design.content.catalog-authoring-boundary`

This proposal is nonbinding. It makes no catalog entry or scenario ready.

The proposed authoring order is:

1. Define water stages and any required petroleum grade, refined product, gas quality, and LNG conversion vocabulary without geography.
2. Author regional scope and resource-process interfaces for reservoir, water, heat, access, and recovery conditions, with no production or price outputs.
3. Close each selected producer lane with legal rights, owner accounts, capacity, inventory, contracts, residual counterparties, and fallback parity.
4. Add extraction, storage, conversion, refinery, desalination, pipeline, terminal, tanker, and route mechanisms only where independent queues or failures matter.
5. Add consumer mechanisms and physical markets, then derive evidence through purchases, availability, sampling, and measurement.
6. Add a futures system only when margin, basis, delivery, or default changes a modeled decision, with separate accounts and clearing rules.
7. Author a period profile with opening state, law, counterparties, residual totals, observation paths, parameter provenance, and calibration bands.

Every stage would run schema, relationship, transmission, ownership, fallback, manifest, freeze, and probe checks before later promotion. The sequence is not authorization to add rows or change a frozen fixture.
