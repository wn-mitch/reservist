# Fidelity and actor behavior

**ID:** `design.representation.fidelity-and-actor-behavior`
**Status:** `canonical`
**Depends on:** `design.representation.representation-axes`, `design.state.cognition-beliefs-and-plans`

Fidelity uses closed models with complete required state, permitted behavior, information boundaries, and persistence contracts. Rust seals each `FidelityModel`. Identity clades define compatible models; each catalog entry narrows that set; a scenario selects exactly one permitted model and supplies every required field. Content cannot assemble optional facets to evade a model contract.

Named cognition is reserved for rare pivotal people with material discretion. Limited role-holder models carry only the state needed to distinguish institutional choices. Decision bodies use represented participants and procedure, institutions use durable state, organization cohorts use response distributions, populations use distributed behavior, and attributed models remain fallible estimates.

Only representations making attributable decisions implement event-driven reconsideration. Each declares wake triggers and bounded candidate-query budgets. Unrelated actors do not scan every event. Capability, disposition, temporary condition, and presentation remain separate. Expertise may provide a clear domain advantage; disposition changes salience and judgment contextually; workload and access affect current performance; satire renders these facts without changing them.

Competent actors can disagree, miss connections, or act under uncertainty. Fidelity never grants hidden truth, inaccessible evidence, or authority outside the represented role.
